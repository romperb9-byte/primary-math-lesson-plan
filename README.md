## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

1. **ប្រអប់បិទភ្ជាប់ឆ្លាតវៃ (Smart Schedule Paste)**៖
   - Copy & Paste អត្ថបទពីតារាងបំណែងចែកកម្មវិធីសិក្សា (ឧ. `១ម៉ / សស. មេ. ៥៖ ប្រវែង ការប្តូរខ្នាតប្រវែង (ទំ.៣៦) / សគ. ជំ.៥ មេ.១៖ សកម្ម. ទី៨ (ទំ.២៥៧-២៥៨)`) ប្រព័ន្ធនឹងផ្គូផ្គងសៀវភៅសិស្ស សៀវភៅណែនាំគ្រូ និងកម្រិតស្ដង់ដារ MCAS ដោយស្វ័យប្រវត្តិ។
   - គាំទ្រការបង្កើតមេរៀនដោយ Gemini AI និងប្រព័ន្ធ Offline Smart Engine រៀបចំមាតិកាស្វ័យប្រវត្តិតាមស្ដង់ដារ។

2. **មាតិកាផ្លូវការទាំង ១០៤ មេរៀន (ថ្នាក់ទី១ ដល់ ទី៦)**៖
   - បញ្ជីទាញទម្លាក់ជ្រើសរើសមេរៀនគ្រប់កម្រិតថ្នាក់ (ថ្នាក់ទី១ ដល់ ទី៦) ដោយផ្ទាល់។

3. **ទម្រង់កិច្ចតែងការបង្រៀនផ្លូវការ (តារាង ៣ ជួរឈរ)**៖
   - ក្បាលទំព័រព្រះរាជាណាចក្រកម្ពុជា ជាតិ សាសនា ព្រះមហាក្សត្រ។
   - វត្ថុបំណង ៣ ផ្នែក (វិជ្ជាសម្បទា បំណិនសម្បទា ចរិយាសម្បទា)។
   - តារាងដំណើរការបង្រៀន ៥ ជំហាន (សកម្មភាពគ្រូ | ខ្លឹមសារមេរៀន | សកម្មភាពសិស្ស)។
   - ចំណុចកំហិតដាច់ខាត **«៣. កំហុស និងគំនិតភាន់ច្រឡំរបស់សិស្ស»** នៅចុងជំហានទី៣ តាមសៀវភៅស្ដង់ដារ MCAS។
   - មុខងារ **Live Edit** កែសម្រួលផ្ទាល់លើតារាងកិច្ចតែងការ។

4. **ស្លាយបង្រៀន ១២ ស្លាយ & សម្ភាររូបីឌីជីថល (Manipulatives & Bar Model)**៖
   - ដ្យាក្រាមរបារ Bar Model (Part-Part-Whole) អន្តរកម្ម។

## 🚀 របៀបដំណើរការក្នុងម៉ាស៊ីន (Local Development)

### លក្ខខណ្ឌតម្រូវ (Prerequisites)
- [Node.js](https://nodejs.org/) (កំណែ 18 ឬខ្ពស់ជាងនេះ)

### ជំហានដំឡើង៖
```bash
# ១. Clone repository
git clone https://github.com/romperb9-byte/primary-math-lesson-plan.git
cd primary-math-lesson-plan

# ២. ដំឡើង dependencies
npm install --legacy-peer-deps

# ៣. បង្កើត .env (ស្រេចចិត្ត សម្រាប់ភ្ជាប់ Gemini API)
# GEMINI_API_KEY="YOUR_GEMINI_API_KEY"

# ៤. ដំណើរការកម្មវិធី
npm run dev
```

បើកកម្មវិធីក្នុង Browser: `http://localhost:3000`
